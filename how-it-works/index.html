How this website works

A website you can message.

There is no dashboard to learn, no plugins to update and no website builder subscription. When something needs to change, you send a message and it is done.

Different from
Squarespace.

Squarespace Built for you
Who puts it togetherYou, filling in a templateI build it for you
To change somethingYou log in and move blocks aroundYou send a message
What you pay forA subscription, every monthOne build price, then small running costs
Fixes and updatesPlugins, themes, and youMe
SpeedDepends on what you have addedPlain pages that load fast
If you leaveYou take what the platform gives youThe pages are yours

Squarespace is a good product. This is a different arrangement rather than a better template: a site built for you, and a person you can message.

How a change
happens.

  1. 1

    You message

    Telegram or WhatsApp, whichever you already use. Send a photo, a new class time, a correction. Say it the way you would say it out loud.

  2. 2

    I make it

    Usually the same day. If it is a bigger job, I tell you when it will be finished.

  3. 3

    It is live

    You get a message back with the link, so you can check it yourself.

What you
pay for.

The build

One price for the site, agreed before I start. Not an hourly meter running while we talk about it.

Running costs, kept small

Hosting, messages and AI all cost money to run, so there is a small amount each month to cover them. You pay for what is used, and quiet months cost less than busy ones. WhatsApp messages are part of this when we set it up.

No platform subscription

You are not renting a website builder. There is no licence, no per person charge and no fee for the site simply existing.

What you never
have to do.

All the jobs that come with running your own website. None of them are yours any more. If you can send it in a message, it can go on the site.

  • Remember a login
  • Update an add-on
  • Fix the layout after an update
  • Renew the security certificate
  • Check that the backup ran
  • Learn a page builder

If you ever
want to leave.

Your site is a set of ordinary files, and they belong to you. Another developer can pick them up, or you can move them somewhere else. Nothing is locked to me.

Send me a message and ask for a change. You can watch it happen.
