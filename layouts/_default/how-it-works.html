How this website works

A website you can message.

There is no dashboard to learn, no plugins to update and no monthly website subscription. When something needs to change, you send a message and it is done.

Different from
Squarespace.

Squarespace is a good product. This is a different arrangement rather than a better template: a site built for you, and a person you can message.

How a change
happens.

  1. 1

    You message

    Telegram or WhatsApp, whichever you already use. Send a photo, a new class time, a correction. Say it the way you would say it out loud.

  2. 2

    I make it

    Usually the same day. If it is a bigger job, I tell you when it will be finished.

  3. 3

    It is live

    You get a message back with the link, so you can check it yourself.

What you
pay for.

The build

One price for the site, agreed before I start. Not an hourly meter running while we talk about it.

Small charges as you go

Every change I make uses a little AI, and that is charged by use, like power. A quiet month costs less than a busy one. There is no monthly plan and no charge per person.

No monthly website bill

You are not renting a website builder, so there is no subscription just to keep the site online.

What you never
have to do.

All the jobs that come with running your own website. None of them are yours any more. If you can send it in a message, it can go on the site.

  • Remember a login
  • Update an add-on
  • Fix the layout after an update
  • Renew the security certificate
  • Check that the backup ran
  • Learn a page builder

If you ever
want to leave.

Your site is a set of ordinary files, and they belong to you. Another developer can pick them up, or you can move them somewhere else. Nothing is locked to me.

Send me a message and ask for a change. You can watch it happen.
